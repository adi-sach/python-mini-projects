# Mouse Position Tracker

A simple Python utility that continuously tracks and displays the current mouse cursor coordinates on the screen.

## Features
- Real-time mouse position tracking
- Displays X and Y coordinates
- Continuously updates cursor position

## Technologies
- Python
- PyAutoGUI

## Installation

```bash
pip install -r requirements.txt
```

## How to Run

```bash
python main.py
```

Press `Ctrl + C` to stop the program.

## Concepts Practiced
- Python loops
- External libraries
- Mouse automation
- Screen coordinates
