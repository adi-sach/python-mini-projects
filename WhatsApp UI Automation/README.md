# WhatsApp UI Automation

A Python desktop automation experiment that interacts with the WhatsApp user interface using mouse and keyboard automation.

## Features
- Automated mouse clicks
- Mouse movement and dragging
- Keyboard shortcut automation
- Clipboard text extraction

## Technologies
- Python
- PyAutoGUI
- Pyperclip

## Installation

```bash
pip install -r requirements.txt
```

## How to Run

```bash
python program.py
```

## Important Notes
- WhatsApp Desktop must be open.
- The script uses fixed screen coordinates.
- Screen resolution and window positioning can affect execution.
- Review the actions before running the script.

## Concepts Practiced
- GUI automation
- Mouse and keyboard control
- Clipboard handling
- Python external libraries
