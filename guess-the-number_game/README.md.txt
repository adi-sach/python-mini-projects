# Guess the Number

A simple command-line game built using Python where the player tries to guess a randomly generated number.

## Features
- Random number generation
- User input for guesses
- Feedback to help the player guess correctly
- Interactive command-line gameplay

## Technologies
- Python
- Random module

## How to Run

1. Make sure Python is installed.
2. Open a terminal in this folder.
3. Run:

```bash
python main.py
```

## Concepts Practiced
- Variables and data types
- Conditional statements
- Loops
- User input
- Random number generation
