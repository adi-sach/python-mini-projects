# Snake Water Gun

A command-line game based on the classic Snake-Water-Gun game, where the player competes against the computer.

## Features
- Player input
- Computer-generated choices
- Automatic winner determination
- Command-line gameplay

## Game Rules
- Snake drinks Water — Snake wins
- Water damages Gun — Water wins
- Gun defeats Snake — Gun wins

## Technologies
- Python
- Random module

## How to Run

```bash
python main.py
```

## Concepts Practiced
- Conditional statements
- Loops
- Random number generation
- User input
- Game logic
